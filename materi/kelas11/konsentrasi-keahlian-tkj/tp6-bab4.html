BAB 4 — Gateway dan Alamat Broadcast dalam Rencana Pengalamatan

Pertemuan 4 · Alokasi Waktu 3 JP · Kelas XI TJKT · Fase F
Tujuan Pembelajaran Bab Ini
  • Peserta didik mampu menjelaskan pengertian dan fungsi gateway.
  • Peserta didik mampu menentukan alamat gateway yang tepat dalam sebuah rencana pengalamatan.

4.1 Masalah yang Diselesaikan oleh Gateway

Bayangkan sekolah kita memiliki dua subnet: subnet ruang guru dan subnet ruang kelas. Kalian sudah tahu dari TP 5 bahwa kedua subnet ini adalah jaringan yang terpisah. Pertanyaannya: bagaimana caranya agar komputer di ruang guru tetap bisa mengirim data ke Chromebook di ruang kelas, atau agar keduanya bisa mengakses internet yang sama?

Jawabannya adalah melalui gateway. Setiap subnet perlu memiliki sebuah “pintu keluar” yang menghubungkannya dengan subnet lain maupun dengan internet. Pintu keluar inilah yang disebut gateway.

Subnet Ruang Guru↔Router / Gateway↔Subnet Ruang Kelas

Gambar 4.1 Gateway menghubungkan subnet ruang guru dengan subnet ruang kelas.

4.2 Pengertian dan Fungsi Gateway

Gateway adalah alamat IP dari perangkat (biasanya router) yang menjadi pintu keluar sebuah jaringan atau subnet menuju jaringan lain. Ketika sebuah perangkat hendak mengirim data ke luar jaringannya sendiri, seperti mengakses internet atau berkomunikasi dengan subnet lain, data tersebut akan dikirim terlebih dahulu ke alamat gateway, baru kemudian diteruskan ke tujuan sebenarnya.

Perumpamaan Gateway sebagai Pintu Gerbang Kompleks

Bayangkan sebuah kompleks perumahan dengan satu gerbang utama untuk keluar-masuk.

Warga yang ingin bepergian ke luar kompleks harus melewati gerbang tersebut terlebih dahulu, meskipun tujuan akhirnya berbeda-beda (sekolah, pasar, kantor).

Gerbang itulah gateway. Warga adalah perangkat dalam jaringan, dan dunia luar kompleks adalah jaringan lain atau internet.

Tanpa gerbang (gateway), warga akan terjebak di dalam kompleks dan tidak dapat pergi ke mana pun.

Bagaimana perangkat menggunakan gateway?

  1. Perangkat memeriksa apakah alamat tujuan berada dalam subnet yang sama.
  2. Jika tujuan berada dalam subnet yang sama, perangkat dapat mengirim data langsung melalui jaringan lokal.
  3. Jika tujuan berada di luar subnet, perangkat mengirim data ke gateway yang telah dikonfigurasi.
  4. Router meneruskan paket berdasarkan informasi rute yang dimilikinya.

Gateway bukan berarti internet itu sendiri. Gateway adalah alamat perangkat perantara yang digunakan untuk mencapai jaringan lain. Koneksi ke internet tetap bergantung pada konfigurasi router dan sambungan internet.

4.3 Menentukan Alamat Gateway

Pada kebanyakan jaringan sederhana, alamat gateway adalah alamat host pertama dalam sebuah subnet, yaitu alamat jaringan (network ID) ditambah 1. Aturan ini bukan keharusan mutlak, namun merupakan kebiasaan yang paling umum digunakan sehingga memudahkan pengelolaan jaringan.

Aturan umum:

Alamat Gateway = Network ID + 1

Contoh 1

Network ID: 192.168.1.0
Gateway: 192.168.1.1

Contoh 2 (subnet hasil pembagian /27)

Network ID: 192.168.1.32
Gateway: 192.168.1.33

Contoh 3 (subnet hasil pembagian /28)

Network ID: 192.168.1.64
Gateway: 192.168.1.65

Perhatikan bahwa alamat gateway pada contoh 2 dan 3 mengikuti pola yang sama: network ID ditambah 1, meskipun angka network ID-nya berbeda-beda karena hasil pembagian subnet. Inilah sebabnya materi TP 5 (subnetting) menjadi bekal penting sebelum mempelajari gateway.

Langkah cepat: pastikan dahulu network ID subnetnya benar. Setelah itu, tambahkan 1 pada alamat terakhir (oktet keempat) jika network ID tersebut berakhir dengan .0, .32, .64, dan seterusnya. Jangan menambahkan 1 pada alamat perangkat secara sembarang; titik awalnya harus network ID subnet.

4.4 Gateway pada Jaringan dengan Banyak Subnet

Ingat kembali bahwa setiap subnet adalah jaringan yang terpisah, sehingga setiap subnet membutuhkan gateway-nya masing-masing, bukan berbagi satu gateway yang sama. Perhatikan contoh berikut untuk jaringan sekolah yang dibagi menjadi tiga subnet, seperti yang telah kalian rancang pada TP 5.

RuanganNetwork IDGatewayRentang Host untuk Perangkat
Ruang Guru192.168.10.0/28192.168.10.1192.168.10.2 – 192.168.10.14
Tata Usaha192.168.10.32/27192.168.10.33192.168.10.34 – 192.168.10.62
Ruang Kelas192.168.10.64/27192.168.10.65192.168.10.66 – 192.168.10.94

Perhatikan bahwa gateway ruang guru (192.168.10.1) tidak dapat digunakan oleh perangkat di ruang kelas, karena keduanya berada pada subnet yang berbeda. Setiap perangkat harus menggunakan gateway yang berasal dari subnet-nya sendiri.

Contoh membaca tabel

Chromebook di subnet ruang kelas menggunakan gateway 192.168.10.65. Perangkat di subnet Tata Usaha menggunakan gateway 192.168.10.33. Walaupun semuanya berada di jaringan sekolah, gateway yang dikonfigurasi harus sesuai dengan subnet perangkat tersebut.

4.5 Mengulang Kembali: Alamat Broadcast dalam Rencana Pengalamatan

Selain gateway, komponen lain yang harus selalu dicantumkan dalam rencana pengalamatan adalah alamat broadcast, yang telah kalian pelajari secara mendalam pada TP 4 dan TP 5. Dalam konteks rencana pengalamatan IP, alamat broadcast berfungsi sebagai penanda batas akhir sebuah subnet, dan wajib dicatat dalam tabel meskipun tidak diberikan kepada perangkat mana pun.

Mengapa alamat broadcast tetap perlu dicatat dalam rencana, padahal tidak dipakai perangkat? Karena tanpa mencatatnya, seorang teknisi dapat secara tidak sengaja memberikan alamat broadcast tersebut kepada sebuah perangkat, sehingga menimbulkan gangguan jaringan. Mencatatnya secara eksplisit adalah bentuk kehati-hatian dalam perencanaan.

Tiga Alamat yang Selalu Dicatat Meski Tidak Dipakai Perangkat
  • Network ID — dicatat di baris pertama tabel, sebagai identitas subnet.
  • Gateway — dicatat sebagai alamat khusus router, bukan perangkat pengguna biasa.
  • Broadcast — dicatat di baris terakhir tabel, sebagai penanda batas akhir subnet.

Contoh batas subnet /28

Untuk subnet 192.168.5.0/28, terdapat 16 alamat dalam satu blok:

Jenis alamatAlamatKeterangan
Network ID192.168.5.0Identitas subnet, tidak diberikan kepada perangkat
Gateway (contoh)192.168.5.1Alamat host pertama, jika dipilih sebagai gateway
Host yang dapat digunakan192.168.5.1–192.168.5.14Rentang alamat host
Broadcast192.168.5.15Alamat terakhir, tidak diberikan kepada perangkat

Ingat: gateway adalah alamat host yang dipilih untuk router. Broadcast adalah alamat khusus subnet dan tidak boleh dialokasikan sebagai alamat perangkat.

Rangkuman Bab 4

  • Gateway adalah alamat IP yang menjadi pintu keluar sebuah jaringan menuju jaringan lain atau internet.
  • Alamat gateway pada umumnya adalah network ID ditambah 1.
  • Setiap subnet memiliki gateway-nya sendiri; gateway satu subnet tidak dapat dipakai oleh subnet lain.
  • Network ID, gateway, dan broadcast selalu dicatat dalam rencana pengalamatan meskipun tidak diberikan kepada perangkat pengguna biasa.
