Rangkuman Bab 2

  • Prefix adalah penulisan singkat subnet mask yang menunjukkan jumlah bit network.
  • Bit host dihitung dengan rumus: 32 dikurangi angka prefix.
  • Semakin besar angka prefix, semakin sedikit bit host, dan semakin kecil ukuran jaringannya.
  • Untuk prefix /24 sampai /30, yang berubah pada subnet mask hanyalah oktet keempat: 0, 128, 192, 224, 240, 248, 252.

Latihan Soal Bab 2

  1. Apa yang dimaksud dengan prefix pada pengalamatan jaringan?
  2. Tuliskan rumus menghitung jumlah bit host dari sebuah prefix!
  3. Tentukan subnet mask dari prefix berikut: (a) /25 (b) /26 (c) /27 (d) /28
  4. Tentukan prefix dari subnet mask berikut: (a) 255.255.255.192 (b) 255.255.255.240 (c) 255.255.255.128
  5. Hitunglah jumlah bit host dari prefix /27 dan /29, lalu tunjukkan cara perhitungannya!
  6. Mengapa /26 memiliki jumlah host lebih sedikit daripada /24? Jelaskan dengan menyebut jumlah bit host masing-masing!

Refleksi Pertemuan 2

  • Mengapa /26 memiliki host lebih sedikit daripada /24?

Cara Membaca Tabel Acuan

Prefix — penulisan singkat subnet mask, misalnya /26.

Subnet Mask — bentuk lengkap prefix dalam empat oktet.

Bit Host — banyaknya bit yang tersisa untuk alamat perangkat.

Block Size — jarak lompatan antar alamat jaringan; dihitung dari 256 dikurangi oktet terakhir subnet mask.

Jumlah Alamat — total alamat dalam satu subnet (termasuk alamat jaringan dan broadcast).

Host Terpakai — jumlah alamat yang benar-benar boleh dipasang pada perangkat (jumlah alamat dikurangi 2).

Perhatikan pola menarik pada tabel tersebut: setiap kali angka prefix bertambah satu, jumlah host yang tersedia menjadi setengahnya. Dari /24 (254 host) menjadi /25 (126 host), lalu /26 (62 host), dan seterusnya. Pola ini dapat membantu kalian mengingat tabel tanpa harus menghafal seluruh angkanya.
