Cara Membaca Tabel Acuan

Prefixpenulisan singkat subnet mask, misalnya /26.
Subnet Maskbentuk lengkap prefix dalam empat oktet.
Bit Hostbanyaknya bit yang tersisa untuk alamat perangkat.
Block Sizejarak lompatan antar alamat jaringan; dihitung dari 256 dikurangi oktet terakhir subnet mask.
Jumlah Alamattotal alamat dalam satu subnet (termasuk alamat jaringan dan broadcast).

Perhatikan pola menarik pada tabel tersebut: setiap kali angka prefix bertambah satu, jumlah host yang tersedia menjadi setengahnya. Dari /24 (254 host) menjadi /25 (126 host), lalu /26 (62 host), dan seterusnya. Pola ini dapat membantu kalian mengingat tabel tanpa harus menghafal seluruh angkanya.

Gambar 6.1 Contoh rancangan pembagian jaringan SMK Negeri 7 Luwu

Langkah pengerjaannya:

RUANG GURU — kebutuhan 10 host
Prefix dipilih : /28 (14 host, cukup untuk 10) Subnet mask : 255.255.255.240 Block size : 256 − 240 = 16 Alamat jaringan: 192.168.10.0 Host : 192.168.10.1 s.d. 192.168.10.14 Broadcast : 192.168.10.15
TATA USAHA — kebutuhan 20 host
Prefix dipilih : /27 (30 host, cukup untuk 20) Subnet mask : 255.255.255.224 Block size : 256 − 224 = 32 Alamat jaringan: 192.168.10.32 Host : 192.168.10.33 s.d. 192.168.10.62 Broadcast : 192.168.10.63
RUANG KELAS — kebutuhan 25 host
Prefix dipilih : /27 (30 host, cukup untuk 25) Subnet mask : 255.255.255.224 Block size : 256 − 224 = 32 Alamat jaringan: 192.168.10.64 Host : 192.168.10.65 s.d. 192.168.10.94 Broadcast : 192.168.10.95

Mengapa Ruang Guru Ditempatkan Paling Awal?

Ruang guru menggunakan /28 dengan block size 16, sehingga hanya memakai alamat 0 sampai 15.

Tata usaha kemudian dimulai dari alamat 32, bukan 16, karena subnet /27 harus dimulai dari kelipatan 32 (0, 32, 64, 96, ...).

Akibatnya alamat 16 sampai 31 tidak terpakai. Hal ini wajar dan masih dapat digunakan nanti apabila ada ruangan baru yang membutuhkan subnet kecil.

Penempatan subnet besar lebih dahulu, lalu subnet kecil setelahnya, akan mengurangi alamat yang terbuang. Cara ini dipelajari lebih lanjut pada materi VLSM di tingkat lanjut.

6.4 Panduan Presentasi

  1. Tampilkan tabel hasil pembagian jaringan kelompok kalian.
  2. Jelaskan alasan pemilihan prefix untuk setiap ruangan.
  3. Tunjukkan cara menghitung block size pada salah satu ruangan.
  4. Jelaskan cara menentukan alamat broadcast dan rentang host.
  5. Jelaskan bagaimana kelompok kalian memeriksa kebenaran hasil perhitungan.
  6. Jawablah pertanyaan atau tanggapan dari kelompok lain.

6.6 Rangkuman Akhir Tujuan Pembelajaran 5

  • Subnetting adalah proses membagi satu jaringan menjadi beberapa subjaringan yang lebih kecil sesuai kebutuhan.
  • Prefix menunjukkan jumlah bit network; bit host dihitung dengan 32 dikurangi angka prefix.
  • Jumlah host dihitung dengan 2^h − 2, dan jumlah subnet dihitung dengan 2^n.
  • Block size dihitung dengan 256 dikurangi oktet terakhir subnet mask, dan digunakan untuk menentukan seluruh alamat jaringan.
  • Pemilihan prefix mengikuti prinsip: paling kecil namun masih mencukupi kebutuhan host.
  • Setiap hasil perhitungan harus diperiksa melalui selisih, kesinambungan, dan jumlah host.
