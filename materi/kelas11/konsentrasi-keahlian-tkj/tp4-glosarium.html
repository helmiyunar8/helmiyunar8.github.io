Glosarium

Istilah

Pengertian

IPv4

Internet Protocol version 4; sistem pengalamatan jaringan sepanjang 32 bit

Alamat IP

Alamat unik yang dimiliki setiap perangkat dalam sebuah jaringan

Bit

Satuan terkecil data dalam komputer, bernilai 0 atau 1

Oktet

Kelompok 8 bit; alamat IPv4 terdiri dari empat oktet

Biner

Sistem bilangan yang hanya menggunakan angka 0 dan 1

Desimal

Sistem bilangan yang menggunakan angka 0 sampai 9

Subnet Mask

Deretan angka yang memisahkan bagian network dan bagian host pada alamat IP

Network Portion

Bagian alamat IP yang menunjukkan jaringan; ditandai mask 255

Host Portion

Bagian alamat IP yang menunjukkan perangkat; ditandai mask 0

Alamat Jaringan

Alamat yang mewakili keseluruhan jaringan; bagian host bernilai 0

Alamat Host

Alamat yang boleh dipasang pada perangkat dalam jaringan

Alamat Broadcast

Alamat untuk mengirim data ke seluruh perangkat sekaligus; host bernilai maksimum

Notasi /24

Penulisan singkat subnet mask 255.255.255.0

IP Conflict

Keadaan ketika dua perangkat memiliki alamat IP yang sama dalam satu jaringan

DHCP

Fitur pada router yang memberikan alamat IP secara otomatis kepada perangkat
