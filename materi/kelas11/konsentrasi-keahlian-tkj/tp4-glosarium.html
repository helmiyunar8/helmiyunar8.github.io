IstilahPengertian
IPv4Internet Protocol version 4; sistem pengalamatan jaringan sepanjang 32 bit
Alamat IPAlamat unik yang dimiliki setiap perangkat dalam sebuah jaringan
BitSatuan terkecil data dalam komputer, bernilai 0 atau 1
OktetKelompok 8 bit; alamat IPv4 terdiri dari empat oktet
BinerSistem bilangan yang hanya menggunakan angka 0 dan 1
DesimalSistem bilangan yang menggunakan angka 0 sampai 9
Subnet MaskDeretan angka yang memisahkan bagian network dan bagian host pada alamat IP
Network PortionBagian alamat IP yang menunjukkan jaringan; ditandai mask 255
Host PortionBagian alamat IP yang menunjukkan perangkat; ditandai mask 0
Alamat JaringanAlamat yang mewakili keseluruhan jaringan; bagian host bernilai 0
Alamat HostAlamat yang boleh dipasang pada perangkat dalam jaringan
Alamat BroadcastAlamat untuk mengirim data ke seluruh perangkat sekaligus; host bernilai maksimum
