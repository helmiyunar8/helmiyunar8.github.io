Kunci Jawaban Latihan Bab 1

1Subnetting adalah proses membagi satu jaringan menjadi beberapa jaringan yang lebih kecil (subnet) dengan cara meminjam sebagian bit host menjadi bit network.
2Lima tujuan: membagi jaringan sesuai kelompok pengguna, menyesuaikan ukuran jaringan dengan kebutuhan, mengurangi penumpukan lalu lintas data, meningkatkan keamanan, dan memudahkan pengelolaan serta penelusuran gangguan.
3Karena meskipun jumlah alamatnya cukup, menyatukan seluruh ruangan dalam satu jaringan membuat data tidak terpisah, keamanan berkurang, lalu lintas menumpuk, dan gangguan di satu ruangan dapat memengaruhi seluruh sekolah.
4Tiga manfaat, misalnya: data tata usaha terpisah dari jaringan siswa, lalu lintas data terbagi sehingga jaringan lebih ringan, dan gangguan lebih mudah ditelusuri.
5Jawaban bervariasi; inti jawaban: aula besar yang dipakai bersama menjadi tidak tertib, sehingga dipasang sekat agar terbentuk ruangan-ruangan kecil yang terpisah meski masih dalam satu bangunan.

Kunci Jawaban Latihan Bab 2

1Prefix adalah penulisan singkat subnet mask menggunakan tanda garis miring diikuti angka yang menunjukkan jumlah bit network.
2Bit host = 32 − angka prefix.
3(a) /25 = 255.255.255.128 · (b) /26 = 255.255.255.192 · (c) /27 = 255.255.255.224 · (d) /28 = 255.255.255.240
4(a) 255.255.255.192 = /26 · (b) 255.255.255.240 = /28 · (c) 255.255.255.128 = /25
5/27 → 32 − 27 = 5 bit host. /29 → 32 − 29 = 3 bit host.
6Karena /26 memiliki 6 bit host (62 alamat host), sedangkan /24 memiliki 8 bit host (254 alamat host). Semakin besar prefix, semakin sedikit bit host yang tersisa.

Kunci Jawaban Latihan Bab 3

1Bit host adalah bagian bit pada alamat IP yang digunakan untuk menandai perangkat, dihitung dengan 32 dikurangi angka prefix.
2Jumlah alamat = 2^h. Jumlah host terpakai = 2^h − 2.
3Karena dalam setiap subnet terdapat satu alamat jaringan dan satu alamat broadcast yang tidak boleh dipasang pada perangkat.
4(a) /25 → h = 7 → 2^7 = 128 → 128 − 2 = 126 host. (b) /27 → h = 5 → 2^5 = 32 → 32 − 2 = 30 host. (c) /29 → h = 3 → 2^3 = 8 → 8 − 2 = 6 host.
5n = 27 − 24 = 3 → 2^3 = 8 subnet. Host per subnet: h = 32 − 27 = 5 → 2^5 − 2 = 30 host.
6/27 memiliki 5 bit host (2^5 − 2 = 30), sedangkan /26 memiliki 6 bit host (2^6 − 2 = 62). Bit host /27 lebih sedikit sehingga hostnya juga lebih sedikit.
7Tidak mencukupi. /27 hanya menyediakan 30 host, sedangkan yang dibutuhkan 40 host. Prefix yang sesuai adalah /26 dengan 62 host.

Kunci Jawaban Latihan Bab 4

1Block size adalah jarak lompatan antar alamat jaringan, dihitung dengan rumus 256 dikurangi oktet terakhir subnet mask.
2(a) /25 → 256 − 128 = 128. (b) /26 → 256 − 192 = 64. (c) /28 → 256 − 240 = 16. (d) /29 → 256 − 248 = 8.
3Dengan menambahkan block size pada alamat jaringan sebelumnya, dimulai dari 0.
4Alamat broadcast adalah satu angka sebelum alamat jaringan subnet berikutnya; untuk subnet terakhir, broadcast-nya adalah 255.
5Block size /26 = 64. Subnet 1: jaringan 192.168.50.0, host .1–.62, broadcast .63. Subnet 2: jaringan .64, host .65–.126, broadcast .127. Subnet 3: jaringan .128, host .129–.190, broadcast .191. Subnet 4: jaringan .192, host .193–.254, broadcast .255.
6Block size /28 = 256 − 240 = 16. Empat subnet pertama: 10.10.10.0 · 10.10.10.16 · 10.10.10.32 · 10.10.10.48.
7Karena alamat jaringan mewakili keseluruhan subnet, sedangkan alamat broadcast digunakan untuk mengirim data ke semua perangkat sekaligus; keduanya memiliki tugas khusus.

Kunci Jawaban Latihan Bab 5

1Agar prefix yang dipilih benar-benar sesuai: cukup menampung seluruh perangkat namun tidak memboroskan alamat.
2Sebagian perangkat tidak memperoleh alamat IP sehingga tidak dapat terhubung ke jaringan. Ini kesalahan fatal.
3Banyak alamat terbuang percuma, sehingga jumlah subnet yang dapat dibuat berkurang dan ruangan lain berpotensi kekurangan alamat.
4(a) 12 host → /28 (14 host), karena /29 hanya 6 host (kurang). (b) 28 host → /27 (30 host), karena /28 hanya 14 host. (c) 50 host → /26 (62 host), karena /27 hanya 30 host. (d) 5 host → /29 (6 host), karena /30 hanya 2 host.
5Karena /28 hanya menyediakan 14 host, tidak cukup untuk 20 perangkat. /27 menyediakan 30 host sehingga mencukupi dan merupakan pilihan terkecil yang cukup.
6Dengan membandingkan jumlah host tersedia terhadap kebutuhan: host tersedia harus lebih besar atau sama dengan kebutuhan, dan pilihan satu tingkat di bawahnya harus sudah tidak mencukupi.
7Prefix /26 (62 host). /27 tidak dapat dipilih karena hanya menyediakan 30 host, sedangkan yang dibutuhkan 32 perangkat.

Kunci Jawaban Evaluasi Akhir

A. Pemahaman Konsep

1Proses membagi satu jaringan menjadi beberapa jaringan yang lebih kecil sesuai kebutuhan.
2Tiga di antaranya: membagi jaringan sesuai kelompok pengguna, meningkatkan keamanan, dan memudahkan pengelolaan jaringan.
3Penulisan singkat subnet mask yang menunjukkan jumlah bit network, misalnya /26.
4Jarak lompatan antar alamat jaringan; rumusnya 256 dikurangi oktet terakhir subnet mask.
5Karena satu alamat digunakan sebagai alamat jaringan dan satu alamat digunakan sebagai alamat broadcast.

B. Hitungan

6/26 → subnet mask 255.255.255.192. Bit host = 32 − 26 = 6 → 2^6 − 2 = 62 host.
7n = 27 − 24 = 3 → 2^3 = 8 subnet.
8Block size = 256 − 240 = 16.
9Block size /26 = 64. Subnet 1: 192.168.40.0, host .1–.62, broadcast .63. Subnet 2: 192.168.40.64, host .65–.126, broadcast .127. Subnet 3: 192.168.40.128, host .129–.190, broadcast .191. Subnet 4: 192.168.40.192, host .193–.254, broadcast .255.
10Prefix /27, karena menyediakan 30 host sehingga mencukupi 28 perangkat, sedangkan /28 hanya menyediakan 14 host yang tidak mencukupi.
