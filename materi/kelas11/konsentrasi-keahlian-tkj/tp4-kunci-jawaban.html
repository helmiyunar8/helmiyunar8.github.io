Kunci Jawaban Latihan Soal

Kunci jawaban ini memuat langkah pengerjaan, bukan hanya hasil akhir. Gunakan untuk memeriksa cara kerja kalian setelah selesai mengerjakan sendiri.

Kunci Jawaban Latihan Bab 1

•     IPv4 adalah sistem pengalamatan jaringan yang memberikan alamat unik kepada setiap perangkat agar dapat saling mengenali dan berkirim data.

•     Empat fungsi: identitas perangkat, alamat tujuan pengiriman data, penunjuk jaringan tempat perangkat berada, dan sarana pengaturan/pengelolaan jaringan.

•     Agar jaringan dapat mengenali setiap perangkat secara pasti dan data terkirim ke tujuan yang tepat; jika sama akan terjadi konflik IP.

•     Tiga akibat: perangkat tidak dapat terhubung, koneksi putus-nyambung, dan data dapat terkirim ke perangkat yang salah.

•     Jawaban bervariasi; inti jawaban: alamat IP seperti alamat rumah yang membuat ‘surat’ (data) sampai ke tujuan yang benar dan tidak boleh kembar.

Kunci Jawaban Latihan Bab 2

•     Panjang 32 bit, terdiri dari 4 oktet (masing-masing 8 bit).

•     Karena setiap oktet 8 bit, jumlah kombinasi = 2⁸ = 256, dihitung mulai dari 0, sehingga nilainya 0 sampai 255.

•     (a) BENAR. (b) SALAH — oktet ke-4 bernilai 256, melebihi 255. (c) SALAH — hanya 3 oktet. (d) BENAR. (e) SALAH — terdapat 5 oktet.

•     Contoh perbaikan: (b) 192.168.1.255 atau 192.168.1.25; (c) 172.16.10.1; (e) 192.168.1.10.

•     Contoh jawaban: 192.168.1.2 · 192.168.1.3 · 192.168.1.4 · 192.168.1.5 (tiga oktet pertama sama, oktet keempat berbeda).

•     10101000 → 128 + 32 + 8 = 168. (bit bernilai 1 berada pada posisi nilai 128, 32, dan 8)

Kunci Jawaban Latihan Bab 3

•     Subnet mask adalah deretan angka yang memisahkan bagian jaringan (network portion) dan bagian perangkat (host portion) pada sebuah alamat IP.

•     Network portion menunjukkan jaringan tempat perangkat berada (ditandai mask 255); host portion menunjukkan perangkat tertentu di dalam jaringan itu (ditandai mask 0).

•     Network portion = 192.168.7 ; Host portion = 88.

•     Ya, satu jaringan. Karena tiga oktet pertama keduanya sama, yaitu 192.168.1; hanya host-nya yang berbeda (20 dan 150).

•     Tidak. Karena network portion-nya berbeda: 192.168.1 dan 192.168.9, sehingga keduanya berada pada jaringan yang berbeda.

•     Artinya alamat IP 192.168.10.5 dengan subnet mask 255.255.255.0 (24 bit pertama adalah bagian network).

Kunci Jawaban Latihan Bab 4

•     Alamat jaringan adalah alamat yang mewakili keseluruhan jaringan, bukan satu perangkat tertentu, dan ditandai dengan bagian host bernilai 0.

•     Langkah: (1) tulis alamat IP, (2) tandai network portion dan host portion, (3) salin network portion lalu ubah host portion menjadi 0.

•     (a) 192.168.3.0 — network 192.168.3, host 77 → 0. (b) 10.5.5.0 — network 10.5.5, host 101 → 0. (c) 172.16.9.0 — network 172.16.9, host 254 → 0. (d) 192.168.250.0 — network 192.168.250, host 2 → 0.

•     Karena alamat jaringan harus mewakili seluruh perangkat; jika host tetap diisi angka, alamat itu sudah menunjuk satu perangkat tertentu.

•     Karena alamat jaringan memiliki tugas khusus sebagai penanda jaringan; jika dipasang pada perangkat akan menimbulkan kekacauan pengalamatan.

•     Kesalahannya: yang diubah menjadi 0 adalah oktet ketiga, padahal seharusnya oktet keempat. Jawaban benar: 192.168.4.0.

Kunci Jawaban Latihan Bab 5

•     Alamat jaringan mewakili keseluruhan jaringan (host = 0); alamat host dipakai perangkat; alamat broadcast untuk mengirim data ke semua perangkat sekaligus (host = 255).

•     Karena alamat jaringan mewakili keseluruhan jaringan, bukan satu perangkat tertentu.

•     Karena alamat broadcast bertugas khusus mengirim data ke seluruh perangkat sekaligus; jika dipakai satu perangkat, fungsi tersebut terganggu.

•     Alamat jaringan 192.168.25.0 · Host 192.168.25.1 s.d. 192.168.25.254 · Broadcast 192.168.25.255.

•     Alamat jaringan 10.0.0.0 · Broadcast 10.0.0.255 · Host 10.0.0.1 s.d. 10.0.0.254 (alamat 10.0.0.150 termasuk host yang sah).

•     254 perangkat. Perhitungan: 256 alamat − 1 alamat jaringan − 1 alamat broadcast = 254. Atau dengan rumus 2⁸ − 2 = 254.

•     Tidak boleh, karena 192.168.1.255 adalah alamat broadcast yang memiliki tugas khusus dan tidak boleh dipasang pada perangkat.

Kunci Jawaban Evaluasi Akhir

A. Pemahaman Konsep

•     IPv4 adalah sistem pengalamatan jaringan sepanjang 32 bit yang memberi alamat unik pada setiap perangkat.

•     Empat oktet; setiap oktet bernilai 0 sampai 255.

•     Memisahkan bagian network dan bagian host pada sebuah alamat IP.

•     Network portion menunjukkan jaringan (mask 255); host portion menunjukkan perangkat (mask 0).

•     Karena akan terjadi konflik IP yang menyebabkan gangguan koneksi dan data salah kirim.

B. Hitungan

•     192.168.8.44 → network portion 192.168.8, host 44 diubah menjadi 0 → Alamat jaringan = 192.168.8.0

•     192.168.8.0/24 → host diisi nilai maksimum 255 → Broadcast = 192.168.8.255

•     10.10.5.0 → Host pertama 10.10.5.1, host terakhir 10.10.5.254 → Rentang = 10.10.5.1 s.d. 10.10.5.254

•     254 host. Perhitungan: 256 − 1 (alamat jaringan) − 1 (broadcast) = 254, atau 2⁸ − 2 = 254.

•     (a) SALAH, 260 > 255 → perbaikan 192.168.1.26 (atau angka lain 0–255). (b) SALAH, hanya 3 oktet → perbaikan 10.0.0.1. (c) BENAR, tidak perlu diperbaiki.
