TP 5 · Subnetting dan Pembagian Jaringan Sederhana

BAB 2 — Contoh Terbimbing

Memahami hubungan prefix, subnet mask, dan bit host.

2.3 Contoh Terbimbing

Contoh 1 — Dari prefix menuju subnet mask:

Sebuah jaringan menggunakan prefix /26. Tentukan subnet mask dan jumlah bit host-nya.

Langkah 1 — Hitung bit host:
32 − 26 = 6 bit host

Langkah 2 — Lihat tabel acuan untuk /26:
Subnet mask = 255.255.255.192

Jawaban: subnet mask 255.255.255.192, bit host 6

Contoh 2 — Dari subnet mask menuju prefix:

Sebuah jaringan menggunakan subnet mask 255.255.255.224. Tentukan prefix dan jumlah bit host-nya.

Langkah 1 — Lihat oktet keempat: 224

Langkah 2 — Cari pada tabel acuan: 224 berpasangan dengan /27

Langkah 3 — Hitung bit host: 32 − 27 = 5 bit host

Jawaban: prefix /27, bit host 5

Contoh 3 — Perubahan dari /24 menjadi /26:

Apa yang terjadi jika jaringan 192.168.1.0/24 diubah menjadi /26?

Sebelum: /24 → 8 bit host → 254 alamat host

Sesudah: /26 → 6 bit host → 62 alamat host

Artinya:
2 bit host 'dipinjam' menjadi bit network,
sehingga jaringan menjadi lebih kecil, tetapi jumlah jaringannya bertambah banyak.
