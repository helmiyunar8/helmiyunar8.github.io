TP 5 · Subnetting dan Pembagian Jaringan Sederhana

BAB 3 — Menentukan Jumlah Subnet dan Jumlah Host

Pertemuan 3 · Alokasi Waktu 3 JP

Tujuan Pembelajaran Bab Ini:

  • Peserta didik mampu menentukan jumlah host yang tersedia pada suatu prefix.
  • Peserta didik mampu menentukan jumlah subnet yang terbentuk dari suatu pembagian.

3.1 Bit Host Menentukan Kapasitas Jaringan

Pada Bab 2, kalian telah mempelajari cara menghitung jumlah bit host dari sebuah prefix. Sekarang kita akan menggunakan angka bit host tersebut untuk menghitung berapa banyak perangkat yang dapat ditampung sebuah jaringan.

Kuncinya sederhana: setiap bit dapat bernilai 0 atau 1, yaitu dua kemungkinan. Apabila terdapat h buah bit host, maka banyaknya kombinasi alamat yang dapat dibentuk adalah 2 dipangkatkan h.

Jumlah seluruh alamat = 2h

dengan h = jumlah bit host

Contoh perhitungan bertahap:

h = 828 = 2×2×2×2×2×2×2×2 = 256 alamat
h = 727 = 128 alamat
h = 626 = 64 alamat
h = 525 = 32 alamat
h = 424 = 16 alamat
h = 323 = 8 alamat
h = 222 = 4 alamat
Cara Mudah Menghitung Pangkat Dua

Kalian tidak perlu menghafal seluruhnya. Cukup ingat bahwa setiap kenaikan satu pangkat berarti dikalikan dua:

2 → 4 → 8 → 16 → 32 → 64 → 128 → 256

Urutan angka inilah yang akan terus kalian pakai dalam subnetting.

3.2 Menghitung Jumlah Host yang Dapat Dipakai

Dari TP 4, kalian sudah mengetahui bahwa dalam setiap jaringan terdapat dua alamat yang tidak boleh dipasang pada perangkat, yaitu alamat jaringan dan alamat broadcast. Hal ini juga berlaku pada setiap subnet. Oleh karena itu, jumlah host yang benar-benar dapat dipakai adalah:

Jumlah host terpakai = 2h − 2

Angka 2 dikurangkan karena:

  • −1 untuk alamat jaringan
  • −1 untuk alamat broadcast
Contoh 1:

Sebuah jaringan menggunakan prefix /26. Berapa jumlah host yang dapat dipakai?

Langkah 1 — Hitung bit host: h = 32 − 26 = 6

Langkah 2 — Hitung jumlah alamat: 26 = 64 alamat

Langkah 3 — Kurangi 2: 64 − 2 = 62 host

Jawaban: 62 host dapat dipakai

Contoh 2:

Sebuah jaringan menggunakan prefix /28. Berapa jumlah host yang dapat dipakai?

h = 32 − 28 = 4

24 = 16 alamat

16 − 2 = 14 host

Jawaban: 14 host dapat dipakai
