Kunci Jawaban Latihan Bab 1

  1. Rencana pengalamatan IP adalah dokumen yang mencatat alamat IP, subnet mask, dan gateway setiap perangkat sebelum jaringan dipasang dan dikonfigurasi.
  2. Agar kesalahan seperti konflik IP dapat ditemukan dan diperbaiki di atas kertas, sebelum perangkat sungguhan dipasang.
  3. Nama perangkat (identitas), alamat IP (identitas unik), subnet mask (penentu network/host), gateway (pintu keluar jaringan), dan keterangan (catatan tambahan).
  4. Karena gateway mewakili pintu keluar jaringan yang sama, sehingga seluruh perangkat dalam satu jaringan menuju pintu keluar yang sama pula.
  5. Jawaban bervariasi; inti jawaban: rencana pengalamatan seperti denah rumah yang menunjukkan letak setiap alamat sebelum jaringan benar-benar dibangun.

Kunci Jawaban Latihan Bab 2

  1. Karena router dan access point juga merupakan perangkat dalam jaringan yang memerlukan identitas berupa alamat IP agar dapat diatur dan berfungsi.
  2. Alamat cadangan adalah alamat yang belum dipakai namun disiapkan untuk pertambahan perangkat di masa depan, agar rencana tidak perlu disusun ulang.
  3. 25 Chromebook + 1 access point = 26. Ditambah cadangan 5 → 26 + 5 = 31 alamat.
  4. Prefix /26 (62 host), karena /27 hanya menyediakan 30 host yang tidak mencukupi 31 kebutuhan.
  5. Ketika ada penambahan perangkat baru, seluruh rencana harus disusun ulang dan berisiko mengganggu perangkat yang sudah berjalan.

Kunci Jawaban Latihan Bab 3

  1. Network ID (untuk alamat jaringan) dan Host ID (untuk alamat host).
  2. Network ID, router (gateway), perangkat jaringan lain, perangkat pengguna, cadangan, lalu broadcast.
  3. Karena router berfungsi sebagai gateway, sehingga secara kebiasaan ditempatkan pada alamat host pertama agar mudah diingat dan dikenali.
  4. Karena keduanya memiliki fungsi khusus (identitas jaringan dan penanda batas akhir) dan tidak boleh dipasang pada perangkat mana pun.
  5. Contoh: Network ID 192.168.9.0, Router 192.168.9.1, Chromebook 1–5 pada 192.168.9.2–.6, sisanya cadangan, broadcast di alamat terakhir subnet.

Kunci Jawaban Latihan Bab 4

  1. Gateway adalah alamat IP yang menjadi pintu keluar sebuah jaringan menuju jaringan lain atau internet; fungsinya meneruskan data yang ditujukan ke luar jaringan.
  2. Alamat gateway umumnya sama dengan network ID ditambah 1.
  3. (a) 192.168.3.1
    (b) 192.168.3.97
    (c) 172.16.5.1
  4. Karena setiap subnet adalah jaringan yang terpisah, sehingga pintu keluarnya (gateway) juga harus berasal dari subnet itu sendiri agar dapat dikenali oleh perangkat di dalamnya.
  5. Jawaban bervariasi; inti jawaban: gerbang kompleks adalah satu-satunya jalan keluar-masuk bagi seluruh warga, sama seperti gateway bagi seluruh perangkat dalam jaringan.
  6. Agar teknisi tidak secara tidak sengaja memberikan alamat broadcast tersebut kepada sebuah perangkat, yang dapat menimbulkan gangguan jaringan.

Kunci Jawaban Latihan Bab 5

  1. Menghitung kebutuhan dasar, menambah cadangan, memilih prefix, menentukan network ID/gateway/broadcast, dan menyusun tabel lengkap.
  2. Karena total kebutuhan (20 alamat) melebihi kapasitas /28 (14 host), sehingga harus menggunakan /27 yang menyediakan 30 host.
  3. Karena router itu sendiri adalah gateway, sehingga tidak memerlukan gateway lain di atasnya untuk perangkat dalam subnet yang sama.
  4. Kebutuhan: 15 + 1 (AP) = 16, + cadangan 3 = 19 → prefix /27 (30 host). Network ID 192.168.3.0, gateway 192.168.3.1, broadcast 192.168.3.31, host untuk 16 perangkat dari .2 sampai .17, sisanya cadangan.

Kunci Jawaban Evaluasi Akhir

A. Pemahaman Konsep
  1. Dokumen yang mencatat alamat IP, subnet mask, dan gateway setiap perangkat sebelum jaringan dipasang.
  2. Nama perangkat, alamat IP, subnet mask, gateway, dan keterangan.
  3. Network ID adalah alamat jaringan; host ID adalah alamat perangkat dalam jaringan tersebut.
  4. Sebagai pintu keluar jaringan menuju jaringan lain atau internet.
  5. Untuk mengantisipasi pertambahan perangkat di masa depan tanpa perlu menyusun ulang seluruh rencana.
B. Hitungan dan Penerapan
  1. 18 + 4 = 22 alamat. Prefix /27 (30 host) mencukupi, karena /28 (14 host) tidak cukup.
  2. 192.168.6.65 (network ID + 1).
  3. Network ID 192.168.7.0, Router 192.168.7.1 (gateway), Chromebook 1–8 pada 192.168.7.2 – .9, sisanya cadangan (.10–.14), Broadcast 192.168.7.15.
  4. Kesalahan: 192.168.8.0 adalah network ID, tidak boleh dipakai perangkat. Perbaikan: berikan alamat host yang sah, misalnya 192.168.8.2.
  5. Akibatnya terjadi konflik IP dan salah satu atau kedua Chromebook tidak dapat terhubung ke jaringan. Perbaikan: ubah salah satu alamat menjadi alamat host lain yang belum terpakai.
