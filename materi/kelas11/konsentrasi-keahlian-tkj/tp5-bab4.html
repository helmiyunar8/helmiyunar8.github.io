4.1 Apa Itu Block Size?

Bab ini adalah bab paling penting dalam TP 5, karena di sinilah kalian akan benar-benar membagi sebuah jaringan menjadi beberapa subnet secara lengkap. Kuncinya terletak pada satu angka yang disebut block size.

Block size adalah jarak lompatan antara satu alamat jaringan dengan alamat jaringan subnet berikutnya. Dengan mengetahui block size, kalian dapat menentukan seluruh alamat subnet hanya dengan cara menjumlahkan secara berurutan, tanpa perlu menghitung biner sama sekali.

Block size = 256 − oktet terakhir subnet mask

Contoh perhitungan block size:

Perhatikan bahwa angka block size selalu sama dengan jumlah alamat dalam satu subnet. Ini bukan kebetulan: block size memang menunjukkan berapa banyak alamat yang "dijatah" untuk setiap subnet.

4.2 Lima Langkah Membagi Jaringan

Berikut adalah lima langkah baku yang akan kalian gunakan setiap kali membagi jaringan. Hafalkan urutannya, karena langkah ini akan dipakai terus sampai proyek akhir di Bab 6.

  1. Tentukan subnet mask dari prefix yang diminta (lihat tabel acuan).
  2. Hitung block size dengan rumus 256 dikurangi oktet terakhir subnet mask.
  3. Tuliskan alamat jaringan setiap subnet dengan cara menjumlahkan block size berulang-ulang, dimulai dari 0.
  4. Tentukan alamat broadcast setiap subnet, yaitu satu angka sebelum alamat jaringan subnet berikutnya.
  5. Tentukan rentang host, yaitu dari alamat jaringan + 1 sampai alamat broadcast − 1.

4.4 Memeriksa Kebenaran Hasil

Setelah menyusun tabel subnet, selalu periksa hasilnya menggunakan tiga cara berikut.

  1. Periksa selisih: jarak antar alamat jaringan harus tepat sama dengan block size (contoh: 0 → 64 → 128 → 192, selisihnya selalu 64).
  2. Periksa kesinambungan: alamat broadcast suatu subnet harus tepat satu angka sebelum alamat jaringan subnet berikutnya (63 lalu 64, 127 lalu 128).
  3. Periksa jumlah host: hitung dari host pertama sampai host terakhir, hasilnya harus sama dengan angka pada tabel acuan (untuk /26 harus 62).

Sebagai contoh pemeriksaan ketiga pada subnet 1: host pertama 1 dan host terakhir 62, maka jumlah host adalah 62 − 1 + 1 = 62 host. Angka ini sesuai dengan tabel acuan untuk /26, sehingga hitungan sudah benar.

Rangkuman Bab 4

  • Block size adalah jarak lompatan antar alamat jaringan, dihitung dengan rumus 256 dikurangi oktet terakhir subnet mask.
  • Alamat jaringan setiap subnet diperoleh dengan menjumlahkan block size berulang mulai dari 0.
  • Alamat broadcast adalah satu angka sebelum alamat jaringan subnet berikutnya.
  • Rentang host adalah dari alamat jaringan + 1 sampai alamat broadcast − 1.
  • Hasil hitungan selalu diperiksa melalui selisih, kesinambungan, dan jumlah host.

Latihan Soal Bab 4
