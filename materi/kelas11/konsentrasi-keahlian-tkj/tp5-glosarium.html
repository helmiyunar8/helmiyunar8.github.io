GLOSARIUM
Gunakan halaman ini sebagai referensi cepat ketika menemukan istilah subnetting yang belum dipahami selama mempelajari TP 5.
1234 567 8910 1112
1Subnetting
Proses membagi satu jaringan menjadi beberapa jaringan yang lebih kecil
2Subnet
Jaringan kecil hasil pembagian dari sebuah jaringan yang lebih besar
3Prefix
Penulisan singkat subnet mask, menunjukkan jumlah bit network (misalnya /26)
4Bit Network
Bagian bit alamat IP yang menunjukkan identitas jaringan
5Bit Host
Bagian bit alamat IP yang menunjukkan identitas perangkat; dihitung 32 − prefix
6Block Size
Jarak lompatan antar alamat jaringan; dihitung 256 − oktet terakhir subnet mask
7Alamat Jaringan
Alamat pertama sebuah subnet; tidak boleh dipakai perangkat
8Alamat Broadcast
Alamat terakhir sebuah subnet; tidak boleh dipakai perangkat
9Rentang Host
Kumpulan alamat antara alamat jaringan dan alamat broadcast
10Meminjam Bit
Mengambil sebagian bit host untuk dijadikan bit network saat subnetting
11Pemborosan Alamat
Keadaan ketika subnet yang dipilih jauh lebih besar dari kebutuhan
12VLSM
Variable Length Subnet Mask; teknik lanjutan membagi subnet dengan ukuran berbeda-beda
